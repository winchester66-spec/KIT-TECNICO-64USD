# BONUS TOOLS INCLUDED IN THE TECH TOOLKIT

## 1. Built-in software updater
- **What it is:** a utility embedded in the toolkit interface that manages the installers.
- **How it works:** lists every one of the 160+ programs with its last update date and downloads the newest installer with a single click.
- **Why it matters:** your USB drive does not become outdated over time. Every client machine leaves with modern software and current security patches.

## 2. Tweaks and optimisation panel
- **What it is:** a dedicated interface for quick Windows adjustments after a format.
- **What it does:** restores system icons ("This PC", "Network", "Control Panel") to the desktop, applies high-performance power plans, clears temporary files, manages OneDrive and repairs Windows Update.
- **Why it matters:** removes the need to dig through Windows 10/11 menus for routine post-format chores.

## 3. Setup tutorials
- Step-by-step guidance in the members area showing how to download the package, extract it, prepare the USB drive and run the launcher and driver panel.
